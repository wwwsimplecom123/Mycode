# ShieldDome 测试与验收报告

## 1. 当前自动化结果

执行命令：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q app shielddome scripts
```

当前结果：12 个测试全部通过，Python 模块编译检查通过。

已覆盖：

- 链接显示地址与真实地址不一致。
- 黑名单域名和敏感意图。
- 实体脱敏与模型上下文隐私。
- RAG 可信样式异常。
- LLM 故障回退。
- EML 解析和邮件认证结果。
- 持久化任务领取、完成与查询。
- 合法 SPF/DKIM/DMARC 邮件仍可因内容钓鱼被判为高风险。
- RAG 知识必须审核后才能参与检索。

## 2. 正式功能验收

1. 上传正常、外部钓鱼、内部钓鱼和恶意附件 EML。
2. 确认快速结果、最终状态、证据、RAG 引用和 LLM 解释可查看。
3. 关闭 LLM/Embedding 网络，确认任务以 `degraded` 结束。
4. 导入 RAG 知识，确认发布前不可检索、发布后可检索、停用后不参与检测。
5. 验证错误 Token 无法访问管理和接入 API。

## 3. 性能与稳定性验收

- 快速检测 P95 小于 500 ms。
- 峰值接入不少于每秒 20 封，日处理目标 10 万封。
- 4 GB Linux 连续运行 72 小时，无任务丢失、永久卡住或内存失控。
- 标注集召回率不低于 90%，精确率不低于 95%。

这些指标必须在目标 Linux 服务器、真实 PostgreSQL、真实 API 配额和企业样本上执行，当前开发环境尚未完成性能与 72 小时稳定性测试。

## 4. 安全验收

- Secret 扫描确认源码、前端、日志和报告无真实 Key。
- 验证 XSS、越权、恶意 MIME、超大文件、压缩包和异常附件。
- 确认原始 EML 在 72 小时后删除。
- 确认 LLM 请求不包含原始附件和未脱敏正文。

## 5. 文档验收

由未参与开发的测试人员在全新 Linux 环境按照文档完成：安装、初始化、上传 EML、RAG 导入审核、模型故障降级、备份和恢复。所有命令、截图和偏差记录在最终验收附件中。
