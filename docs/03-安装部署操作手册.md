# ShieldDome 安装部署操作手册

## 1. 前置条件

- Ubuntu 22.04/24.04 或兼容 Debian Linux。
- 最低 4 vCPU、4 GB RAM、100 GB SSD。
- Root 权限、可用内部 DNS 名称和 TLS 证书。
- PostgreSQL 可安装 `vector` 扩展。

## 2. 安装

```bash
cd /path/to/ShieldDome
sudo bash scripts/install-linux.sh
```

脚本安装 Nginx、PostgreSQL、Python、Node 构建工具，将应用复制到 `/opt/shielddome`，创建服务账号并生成 systemd 配置。

## 3. 初始化 PostgreSQL

```bash
sudo -u postgres psql <<'SQL'
CREATE USER shielddome WITH PASSWORD '替换为强随机密码';
CREATE DATABASE shielddome OWNER shielddome;
\c shielddome
CREATE EXTENSION IF NOT EXISTS vector;
SQL
```

编辑 `/etc/shielddome/shielddome.env`：

```bash
sudo chmod 600 /etc/shielddome/shielddome.env
sudo editor /etc/shielddome/shielddome.env
```

必须替换数据库密码、Bootstrap 管理员密码、管理员 Token、接入 Token和已经撤销后重新生成的硅基流动 Key。首次启动后使用 `SHIELDDOME_BOOTSTRAP_ADMIN_USERNAME` 与 `SHIELDDOME_BOOTSTRAP_ADMIN_PASSWORD` 登录控制台。

生成原文加密密钥并写入 `SHIELDDOME_DATA_ENCRYPTION_KEY`：

```bash
python3 -c "import base64,secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())"
```

```bash
cd /opt/shielddome
sudo -u shielddome -E .venv/bin/python scripts/initialize.py
```

## 4. TLS 与 Nginx

将证书放入：

```text
/etc/shielddome/tls/fullchain.pem
/etc/shielddome/tls/privkey.pem
```

如果暂时没有 TLS 证书，可先使用 HTTP 访问；测试时请确保仅在受信内部网络中部署。

修改 `/etc/nginx/sites-available/shielddome` 的 `server_name`，然后执行：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

已有部署临时启用 HTTP 时，可执行：

```bash
cd /opt/shielddome
sudo bash scripts/enable-http-linux.sh
sudo ufw allow 80/tcp
curl http://127.0.0.1/api/v1/health
```

还需要在云服务器安全组中放行入站 TCP `80` 端口。浏览器插件填写 `http://服务器公网IP`，不要填写后端内部端口 `8000`。

该脚本会备份现有 ShieldDome Nginx 配置到 `/etc/nginx/sites-available/shielddome.before-http`，并切换为仅监听 `80` 的测试配置。

## 5. 启动与验证

```bash
sudo systemctl enable --now shielddome-api shielddome-worker nginx
curl -k https://shielddome.example.internal/api/v1/health
curl http://shielddome.example.internal/api/v1/health
```

预期返回 `status: ok`。浏览器打开站点后，在“模型 API 设置”页保存管理员访问 Token。

## 6. 升级与卸载

```bash
sudo bash scripts/backup.sh
sudo bash scripts/upgrade-linux.sh
sudo bash scripts/uninstall-linux.sh
```

卸载脚本故意保留 `/var/lib/shielddome` 与 `/etc/shielddome`，防止误删数据和密钥。
